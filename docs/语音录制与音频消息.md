# 语音录制与音频消息

## 类型与发送链路

语音属于音频文件消息。Java 的 `FileTypeConstant.AUDIO=4`，`MinIOFileStorgeUtil.getBucketName(4)` 使用音频 bucket；Electron 的 `MessageContentManage` 也把 `msgType=4` 交给 `ChatAudioView`。`msgType=3` 是视频，部分旧 DTO 注释中的顺序不准确。

| 消息 | 处理 |
| --- | --- |
| 文本，msgType=1 | 生成 Snowflake 消息 ID，直接发送私聊/群聊 WS，等待 ACK |
| 语音，msgType=4 | 录音→保存本地音频→复用文件分片上传与合并、REST 预存→两者完成后用同一个消息 ID 发送 WS→ACK |

录音没有另开后端上传接口，也没有把音频字节塞进文本 WS。录音的 Blob 通过窄 IPC 提交给主进程，主进程生成文件名并写入现有文件保存位置下的日期/voice 目录。WebM 可以只有音轨，因此录音明确标记为类型 4，不使用将 `.webm` 判为视频的附件扩展名推断。

上传与 REST 预存可能以不同顺序完成。修复了短录音上传过快、预存未完成就发 WS 的竞态；成功/失败状态回写也等待预存结果，避免更新不存在的记录。重复完成通知不会重复投递。分片请求失败会停止该文件 worker、通知来源窗口并显示发送失败。

## 操作与界面

聊天工具栏新增麦克风按钮：点击开始录音→结束录音→试听→发送；可以取消、重录，前台录音范围为 1–60 秒。发送语音保留原有文字草稿。

- 麦克风缩放、光圈和频谱由真实 `AnalyserNode` 输入音量驱动，动画平滑。取消、关闭、切换会话和卸载时释放麦克风、AudioContext、计时器与 Blob URL；权限请求迟到也不会留下采集中的麦克风。
- 语音气泡支持播放/暂停、时长、进度拖动、播放波形和加载重试；同一窗口只播放一段语音。优先使用本地音频，失效时回退远程地址。
- 使用既有主题变量，适配浅色/深色；录音面板和气泡都支持减少动画设置。气泡波形是播放提示图形，录音面板的音量和频谱则来自实际采集数据。
- 主聊天页和独立聊天窗口共用 `ChatBase`；上传进度/完成通知回到发起上传的窗口。

## 代码职责

- `components/ChatAudioView.vue`：语音气泡、播放与进度。
- `components/VoiceRecorderPanel.vue`：录音面板和提交交互。
- `composables/useVoiceRecorder.ts`：权限、采集、音量分析、资源释放。
- `main/File/voiceRecording.js`：录音字节/时长/类型声明校验、生成本地文件及文件消息信息。
- `ChatBase.vue`：录音和附件共享文件发送入口，沿用当前 Snowflake ID。
- `fileTransferHandlers.js`：协调上传状态与 REST 预存，保证 WS 投递条件及去重。

录音使用原生 [MediaStream Recording](https://www.w3.org/TR/mediastream-recording/) 能力，按支持情况选择音频 MIME，并在停止录制的最终数据事件后生成 Blob；没有新增依赖。macOS 打包配置原本已有 [Electron 麦克风权限所需的用途说明](https://www.electronjs.org/docs/latest/api/system-preferences#systempreferencesaskformediaaccessmediatype-macos)，本次没有修改系统权限设置。

- `npm run build` 通过，包含 ESLint、严格类型检查、全量 Node 回归和主进程/预加载/渲染进程构建。ESLint 为 0 错误、25 条原有未使用项警告，未扩大清理范围。
- 新增 6 项 Node 回归：录音字节落盘且类型为 4、无效输入拒绝、上传先完成、REST 先完成与上传失败、来源窗口回调、分片失败停止 worker 并通知失败。
- `tests/voiceMessage.electron.cjs` 使用真实 Chromium MediaRecorder、AudioContext、Vue 页面和录音保存代码，验证了录制/试听/取消、音量响应、480px 窗口、双击去重、文字草稿保留、同 ID 文件 WS、播放互斥、上传失败及权限拒绝/迟到授权清理。网络和数据库边界使用隔离夹具。
- 既有 `tests/desktopPages.electron.cjs` 通过，覆盖共享测试夹具、主题、窗口、钱包等实际页面渲染。
- `git diff --check` 通过；检查了保存的浅色、深色、试听和窄窗口截图。

本次没有向真实好友发送语音，也没有验证真实麦克风设备和真实 MinIO/后端的完整投递。没有生成安装包。由于包含主进程与 preload 修改，开发时需要重启整个 Electron 进程；只刷新 Vue 页面不会加载新的录音 IPC。

# 账号设置、通知与个人动态主页

## 启用

重新启动 `im-auth`、`im-moments` 和 Electron。包含主进程与 preload 修改，仅刷新渲染页面不能完整启用。

本次使用现有用户资料和帖子表，不新增数据库字段或依赖。此前会话已读游标的迁移属于另一个功能，见《未读消息与免打扰》。

## 账号设置

- 打开设置的账号页面时，调用 `GET /user/me` 读取当前用户资料。
- 保存调用 `POST /user/updateInfo`，仅允许修改账号、邮箱和生日，用户身份来自登录上下文。
- 账号为 1–64 位字母、数字或下划线；邮箱选填且不超过 100 字符；生日不能晚于今天。
- 账号、邮箱检查重复；数据库唯一约束处理并发冲突。清空邮箱保存为 NULL，清空生日保存为 NULL。
- 同一事务修改 `user_info` 和 `user_auth` 的账号。密码、手机号继续沿用现有资料。
- 服务端成功后才更新本地缓存与界面；失败保留输入。接口返回安全资料 VO，不包含密码。

## 通知设置

保留并接入现有主进程消息处理的选项：消息提醒总开关、提示音与试听、私聊提醒、群聊提醒、托盘闪烁、定时免打扰。

删除没有处理链路的桌面通知弹窗、通知内容详情、多个提示音类型、@ 我的消息、任务栏未读数字选项。`flashTaskbar` 是已有存储键，界面名称修正为实际生效的“托盘图标闪烁”。

开关即时保存到本机 `notificationSettings`。关闭提醒、关闭某类提醒或进入免打扰时段，只停止声音和托盘提醒，消息与未读统计继续处理；会话自身免打扰仍优先生效。定时免打扰支持跨午夜，起止相同时表示全天。

## 好友预览和个人主页

- 好友详情请求指定作者最近五条帖子，单行只展示前四条。
- 无动态显示“暂无动态”；请求失败显示重试，不把网络失败显示成无动态。
- 超过四条显示省略按钮，打开该好友的独立主页；点击“朋友圈”标题也可打开主页。
- 点卡片打开现有帖子详情窗口。卡片提取首图和纯文本，不直接插入帖子 HTML。
- 世界频道“我的帖子”打开同一主页；点击频道中的作者头像/名字打开作者主页。
- 主页按抖音个人页的结构展示头像、昵称、身份信息、动态总数和封面网格，支持分页、刷新、详情。
- 自己查看自己时显示发布、编辑、删除；查看他人不显示这些入口。后端同时校验编辑与删除的作者身份。
- 发布、修改、删除通过现有跨窗口 `moments:updated` 事件刷新频道、好友预览和主页；修改账号后更新已打开的自己主页。
- 主页与帖子详情窗口再次打开时切换目标，旧请求不会覆盖新目标。编辑窗口存在未保存修改时保留当前内容并提示先保存或关闭。

复用 `views/moments/UserMoments.vue`，移除原 `MyPosts.vue` 及其内部页面路由。好友预览拆为 `components/FriendMomentsPreview.vue`，窗口入口与摘要提取分别位于 `utils/momentWindows.ts`、`utils/momentPresentation.ts`。

## 接口补充

| 接口 | 用途 |
| --- | --- |
| `GET /user/me` | 当前登录用户的安全资料 |
| `POST /user/updateInfo` | 修改当前账号、邮箱、生日 |
| `GET /moments/my?page=1&pageSize=12` | 沿用现有自己帖子接口 |
| `GET /moments/user/{userId}?page=1&pageSize=5` | 新增按作者查询，供好友预览和他人主页复用 |

按作者分页沿用现有 Mapper，过滤 `is_deleted = 0`，按 ID 倒序，页大小限制在 1–50。帖子与作者 ID 返回字符串，避免 JavaScript 大整数精度问题。没有新增关注、粉丝、私密动态等未具备协议支持的功能。

## 验证边界与人工检查

依照用户要求，本次未运行自动测试、构建或实际接口联调，未执行数据库操作。以下需要人工确认：

1. 修改账号、邮箱、生日，重新打开设置确认回显；使用新账号和原密码登录。重复账号、重复邮箱、未来生日应提示失败并保留输入。
2. 点击提示音试听；分别切换提醒总开关、私聊/群聊开关、托盘开关、免打扰时段，确认效果与界面描述一致，消息和未读数继续更新。
3. 分别查看没有动态、1–4 条动态、超过 4 条动态的好友；确认单行四张卡片、省略入口与空状态。连续切换好友不应串数据。
4. 从好友省略按钮、作者头像、“我的帖子”打开主页；在已打开的窗口中切换自己和别人，确认内容及操作按钮更新。连续打开不同帖子，应切换到相应详情。
5. 在自己主页发布、编辑、删除，确认主页、频道和好友预览刷新。查看他人没有编辑、删除按钮，接口也不能操作他人帖子。
6. 超过 12 条动态时加载更多；断网失败后重试不应跳过页码；当前编辑未保存时再打开另一条编辑，不应丢失内容。

## 接入

- src/preload/uiSounds.js 通过文档事件委托统一接入，主窗口、子窗口以及独立截图、加载页都使用同一入口。
- 优先识别按钮、链接、菜单、开关和选项等语义控件；历史 div/span 操作入口通过 pointer 光标识别，不要求逐页添加点击逻辑。
- 按下时播放以减少延迟；原生键盘 click 另行覆盖，避免鼠标事件和 label 转发给 input 时重复播放。
- 禁用、aria-disabled、inert 控件不播放；脚本合成事件不播放。
- 悬停在首次真实交互后启用，并等待 70ms，避免窗口刚打开就发声；离开或失焦取消待播放反馈。
- 点击音效限频 45ms；悬停限频 140ms，点击后 220ms 内不播放悬停。每个窗口任意时刻最多一条界面音效，点击优先。
- 复用五个预加载播放器。页面离开时移除监听、清理计时器并释放音频资源。
- 原有消息提示音逻辑保持独立。没有更改按钮业务行为、窗口拖拽或主题逻辑。

## 验证

- npm run build：通过，包括 ESLint、Vue 类型检查、原有 88 项回归和构建；保留原有 25 条未使用变量警告及字体资源提示。
- npm run test:sounds：使用真实构建 preload，在 Vue 登录页和独立页面分别验证资源解码及实际 play Promise 成功、鼠标按下、键盘 Space、自定义入口、禁用状态、选择/删除/截图音色、label 防重复、脚本事件静默、快速连点、悬停、播放被阻止时业务可用、页面离开清理和重载不累积监听。测试使用覆盖式假按钮，不提交登录、充值或提现请求。
- 音效限频只限制声音；测试验证五次快速点击仍执行五次按钮逻辑。
- 需要重新加载 Electron / preload 才能在已有窗口中生效。

# 本机账号与快捷登录

点击登录页账号输入框右侧的下拉箭头，可查看本机最近成功登录的账号。选择已保存登录状态的账号后，客户端向服务端验证长期 Token，验证通过才进入主界面；未保存或凭据失效的账号需要重新输入密码和验证码。下拉列表也支持移除历史账号。

## 数据保存

| 位置 | 保存内容 | 用途 |
| --- | --- | --- |
| SQLite `device_user_record` | 用户 ID、账号、昵称、头像、首次/最近登录时间、记住登录标记、首次同步完成标记 | 展示历史账号，判断是否需要首次同步 |
| electron-store `accountTokens[userId]` | 经 Electron `safeStorage` 加密后转为 Base64 的长期 Token | 按账号保存可恢复的登录凭据 |
| electron-store 原有用户字段 | 当前账号的 `userId`、`account`、`username`、`avatar`、`accessToken` 等 | 兼容现有业务模块 |
| 主进程内存 | 当前账号的长期 Token、会话版本和登录/刷新中的任务 | 不勾选记住登录状态时维持本次会话，隔离切换前后的请求 |

密码只用于本次登录，不写入 SQLite 或 electron-store。长期 Token 不写入数据库，也不作为明文写入 electron-store。Base64 只是加密结果的存储格式，加密由 `safeStorage` 完成。

“记住登录状态”默认不勾选；系统无法提供安全加密存储时禁用此选项，仍可使用密码登录。不勾选时，关闭并重新启动应用后需输入密码。

现有 `storeGetUserInfo('userId')`、`storeGetUserInfo('account')` 等接口继续使用。`storeGetUserInfo('token')` 由主进程兼容读取当前长期 Token；历史账号列表不会返回任何 Token 或密码。新登录、快捷登录和刷新流程由 `accountApi` 调用主进程处理。

## 操作含义

| 操作 | 历史账号列表 | 当前账号的已记住凭据 | 聊天数据 |
| --- | --- | --- | --- |
| 关闭应用 | 保留 | 勾选记住时保留 | 保留 |
| 托盘“切换账号”/确认登录页“其他账号” | 保留 | 保留已记住的凭据 | 保留 |
| 托盘“退出登录” | 保留 | 清除当前账号本机凭据，其他账号不受影响 | 保留 |
| 登录页移除历史账号 | 删除所选记录 | 清除所选账号本机凭据 | 保留 |

切换账号时断开旧 WebSocket、取消上传、关闭子窗口并重新载入登录页。会话版本校验会忽略切换前迟到的登录、Token 刷新和页面请求结果，避免覆盖新账号的登录状态。

网络或服务暂时异常时保留已保存凭据；服务端明确认定凭据失效时，清除对应账号的凭据并要求密码登录。

## 自动升级

启动时自动迁移原有 `device_user_record`，不需要手动删表或清空本地数据：

- 用户 ID 改为 `TEXT`，旧整数 ID 在 SQLite 内转换，避免经过 JavaScript 数字导致精度丢失。
- 保留原有登录时间、设备和版本字段。旧记录视为已完成首次数据同步；新登录账号单独记录同步完成状态。
- 补齐账号、昵称、头像、记住登录和数据初始化字段。
- 用旧 electron-store 中当前账号的资料补齐历史记录；原来只有用户 ID、没有账号资料的其他旧记录，在该账号再次成功登录后补齐显示信息。
- 旧 `token` 在安全存储可用时迁入当前账号的加密凭据；旧 `token`、`password` 明文键会删除。安全存储不可用时，旧 Token 仅用于本次进程，重启后重新登录。

## 服务端接口

快捷登录改为 `POST /user/pendingLogin`：

```http
Authorization: <长期 Token>
Content-Type: application/json

{"userId":"用户ID"}
```

服务端校验 JWT 签名和有效期、JWT 所属用户、Redis 会话是否仍存在及所属用户，随后返回最新账号资料，并在响应头返回新的短期/长期 Token。用户 ID 以字符串返回，避免长整型精度丢失。

旧 `GET /user/pendingLogin?token=...` 不再支持，Token 不放入 URL。保留服务端原有同一用户登录轮换策略，其他设备登录可能使本机保存的旧凭据失效。

## 启用与验证

重启或重新部署 `im-auth` 和 Electron 客户端后使用。网关修改只涉及移除 Token 日志；部署网关可同步生效。首次启动会自动迁移本地表。

账号迁移、凭据隔离、快捷登录页面逻辑、刷新与退出回归，桌面端类型检查及生产构建已验证。服务端校验及控制器测试通过内存编译执行；完整 Maven 测试受本机输出目录写入权限限制。尚未完成真实账号联调与登录页视觉验收。
